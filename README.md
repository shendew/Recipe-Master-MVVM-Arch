# RecipeMaster AI 🍳

RecipeMaster AI is a modern Android application that transforms a list of available ingredients into a professional chef-curated recipe using Generative AI. Built with a focus on clean architecture and automated workflows.

## ✨ Features
* **AI Recipe Generation:** Leverages Gemini AI to create creative recipes from user-inputted ingredients.
* **Smart UI:** Interactive ingredient management with RecyclerView and smooth Lottie animations.
* **Dark Mode Support:** Fully optimized themes for comfortable cooking at any time of day.
* **Validation:** Built-in guards to ensure only food-related inputs generate results.

## 🏗️ Architecture & Tech Stack
* **MVVM Pattern:** Strict separation of concerns for a scalable and testable codebase.
* **Live Data & ViewModel:** Reactive UI updates that survive configuration changes.
* **Lottie (dotLottie):** High-performance, lightweight animations for a polished UX.
* **Material Design 3:** Modern UI components and styling.

## 🚀 DevOps & CI/CD
* **GitHub Actions:** Integrated CI pipeline that automatically:
  * Triggers on every push and pull request.
  * Runs Gradle linting and unit tests.
  * Ensures build stability before merging.
